What it is

A desktop terminal for macOS and Linux, built around Claude Code. Agents run side by side in tabs and split panes; the fleet view puts every agent and sub-agent on one live timeline with its cost; a scratchpad under each terminal holds your prompts. It sets up each project with its own pinned copy of the method and BMAD v6.

You don’t need it. Everything on the rest of this site runs in any terminal with the ade command.

With a hub

Inside the app, ade work opens a focus agent as a sub-terminal in the app instead of a new window, and ade open opens a file in the app.
